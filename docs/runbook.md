# Runbook

End-to-end operating procedure for the Azure AD cyber range: build, verify,
attack, record, and — most importantly — destroy.

Read `docs/cost.md` before `terraform apply`. The range costs roughly
**$2.36/hour** while it exists.

---

## 0. Prerequisites

| Tool | Minimum | Notes |
|------|---------|-------|
| Azure CLI (`az`) | 2.50+ | `az login` against the free-trial subscription |
| Terraform | 1.6+ | Provides the `azurerm` provider |
| Ansible | 2.15+ | `ansible.windows`, `community.windows`, `community.general` |
| `jq` | any | Used by `preflight.sh` |
| OpenVPN client | any | Runs on the Kali attack box |

```bash
# Ansible collections
ansible-galaxy collection install \
  ansible.windows community.windows community.general
```

Secrets stay out of git. Copy the examples and edit locally:

```bash
cp .env.example .env
cp terraform/terraform.tfvars.example terraform/terraform.tfvars
chmod 600 .env
```

Admin credentials are generated by Terraform and stored in Azure Key Vault by
default. Set `RANGE_ADMIN_PASSWORD` (and `RANGE_ADMIN_USER`) in `.env` only if
you want to pin them.

---

## 1. Preflight and cost check

```bash
./scripts/preflight.sh              # or: make preflight
```

This confirms `az` is authenticated, the subscription is **Enabled**, and
best-effort-detects a free-trial/credit marker. It is read-only against Azure.

Then confirm the live estimate:

```bash
cd terraform && terraform output estimated_hourly_cost_usd && cd -
```

---

## 2. Provision Azure infrastructure

```bash
./scripts/deploy.sh                # or: make deploy
```

This runs preflight, prints the cost estimate, asks you to type `apply`, then
runs `terraform init/fmt/validate/plan/apply` and regenerates the Ansible
inventory. The provider config purges Key Vault and disk soft-delete on
destroy, so teardown is clean.

> The **VPN gateway takes 30–45 minutes** to deploy. That is normal. Do not
> destroy/recreate it repeatedly within a session.

---

## 3. Generate the Ansible inventory

`deploy.sh` already does this, but you can regenerate it any time:

```bash
./scripts/generate-inventory.sh    # or: make inventory
```

Output: `ansible/inventory/hosts.yml` (git-ignored), built from Terraform
outputs. Credentials appear as `__FETCH_FROM_KEY_VAULT__` placeholders until
filled from Key Vault.

---

## 4. Connect the VPN

1. Download the point-to-site VPN root certificate and client package from the
   gateway (`terraform output` lists the connection details, or use the Azure
   portal -> *Virtual network gateway* -> *Point-to-site configuration*).
2. Install the root certificate into your Kali trust store.
3. Bring up the tunnel:

```bash
sudo openvpn --config ~/azure-vpn/corp.ovpn &
ip -brief address | grep -E '172\.16\.'   # expect a 172.16.10.x address
```

DNS for `corp.contoso.lab` should now resolve through the DC's resolver.

---

## 5. Configure the range

```bash
ansible-playbook -i ansible/inventory/hosts.yml ansible/site.yml
```

The play builds, in order: forests -> child domain -> trusts -> directory
structure -> domain joins -> misconfigurations -> SharpHound staging ->
attack-box verification.

Target a subset with tags:

```bash
# One scenario only
ansible-playbook -i ansible/inventory/hosts.yml ansible/site.yml --tags kerberoast

# Everything except the seeded misconfigurations (clean baseline)
ansible-playbook -i ansible/inventory/hosts.yml ansible/site.yml --skip-tags misconfig

# Re-verify the attack box
ansible-playbook -i ansible/inventory/hosts.yml ansible/site.yml --tags kali
```

Syntax-check without touching Azure:

```bash
make syntax
```

---

## 6. Verify the build

- **Trusts and replication**: on `DC01`,
  `Get-ADTrust -Filter *`, `repadmin /showrepl`,
  `Get-ADDomainController -Filter *`.
- **Seeded objects**: `Get-ADUser -Filter * | measure`,
  `Get-ADGroupMember Tier1_Admins`.
- **Attack box**: re-run `--tags kali`; it fails loudly if DC port 445 is not
  reachable, which almost always means the VPN is down.

## 7. Collect BloodHound data

SharpHound is staged on `SRV-MGMT01` at `C:\RangeShare` (share name
`RangeShare`) with a helper script. SharpHound.exe is **not** vendored; drop
your own copy into `ansible/roles/sharphound/files/` before running, or place
it on the share over the VPN.

```bash
# From Kali, over the VPN, run the staged collector as a domain user.
smbclient //srv-mgmt01.corp.contoso.lab/RangeShare -U 'corp.contoso.lab\eevans'
# inside: put SharpHound.exe, then run Collect-BloodHound.ps1 on the host,
# or run SharpHound directly from a joined box if you have one.
```

Retrieve `range-bloodhound.zip` and feed it to the engine.

## 8. Analyse with the attack-path engine

```bash
cd attack-path-engine
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,llm]"

# Deterministic (no key needed)
ap-engine analyze --bloodhound ../range-bloodhound.zip --offline --print

# With an LLM for ranking + narrative (set USER_LLM_* in .env first)
ap-engine analyze --bloodhound ../range-bloodhound.zip --out ./reports
```

Reports land in `reports/`: `attack-path-report.md`, `.html`, `.json`.

## 10. Destroy (do this every session)

```bash
./scripts/destroy.sh               # or: make destroy
az group list -o table             # confirm nothing is left
```

Destroying the resource group is the **only** thing that stops disk billing.
Auto-shutdown stops compute, not disks.

## 11. Troubleshooting

| Symptom | Likely cause / fix |
|---------|-------------------|
| `preflight.sh` fails on `az` | `az login`; confirm the subscription is the free-trial one |
| VPN connect but no DNS | Re-download the client package; ensure the DC is the DNS server |
| `kali` verify fails on port 445 | VPN not up, or NSG/ASG not applied to the client pool |
| WinRM timeouts during Ansible | Increase `ansible_winrm_*_timeout_sec` in `group_vars/all.yml` |
| AD CS ESC1 template warning | Create the template manually — see `docs/scenarios/05-adcs-esc1.md` |
| VMs stop mid-session | `enable_auto_shutdown` fired; change `auto_shutdown_time` or destroy |
| Costs climbing | `terraform output estimated_hourly_cost_usd`; destroy if done |

## Cost discipline

- Default auto-shutdown is on; treat it as a safety net, not a plan.
- Build -> seed -> test -> record -> destroy in one sitting.
- A full cycle fits in **$25–60** of the $200 credit (see `docs/cost.md`).
